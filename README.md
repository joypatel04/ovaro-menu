# Ovaro Chula Chicken — menu link

Live at **https://joypatel04.github.io/ovaro-menu/** (this is the link printed in the QR codes on the visiting cards and flex banners. Never rename this repo or turn off Pages, or the printed QR codes stop working).

## Updating the menu
Replace `menu.pdf` with the new menu (same file name) and commit. The site updates in ~1 minute. Nothing else needs to change.

On GitHub web: open `menu.pdf` → ⋯ → Delete, then "Add file → Upload files" → drop the new `menu.pdf` → Commit. Or just upload with the same name to overwrite it.
